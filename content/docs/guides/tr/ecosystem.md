## Amaç ve sınırlar

MESA Data gözden geçirilmiş Türk hukuk verisi sürümlerini hazırlar. Core; hafıza kabulü, kanonik durum ve retrieval sahibidir. Law, V4 HTTP sözleşmesini tüketir; güncel canlı entegrasyon doğrulanmamıştır. QA, baseline dışında davranışı sınar. E2E Certification dış kanıtlarla dondurulmuş Data → Core profilini değerlendirir; B4/B6/B7/B8 receipt’leri ve yeni resmî PASS halen eksiktir.
