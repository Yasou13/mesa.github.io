## Purpose and boundaries

The legacy direct stdio server and V4 HTTP gateway/local bridge have different runtime contracts. A dataset-bound bridge keeps server-authorized scope and does not expose mutating global rebuild. Tool availability is capability-dependent; it does not bypass authentication or make graph traversal operational.
