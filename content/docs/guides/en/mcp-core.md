## Purpose and boundaries

Run `mesa start` then `mesa mcp-config` for the direct V4 stdio configuration. This path uses client-side tool approval and the API key’s grants without a local control database. The HTTP gateway/bridge has its own bindings, policy and audit lifecycle. A dataset-bound bridge keeps server-authorized scope and does not expose mutating global rebuild. Tool availability is capability-dependent; it does not bypass authentication or make graph traversal operational.
