code, fixture values, profile names, and storage/product names stay unchanged.

## Never translate

MESA, MESA Core, MESA Data, MESA QA, MESA E2E Certification, MESA Law,
SQLite, LanceDB, Kùzu, MCP, HTTP, Python, BM25, RRF, package names, methods,
JSON fields, fixture identities, profile names, version strings, and official
source names such as Resmî Gazete, Mevzuat, AYM, and Yargıtay.
