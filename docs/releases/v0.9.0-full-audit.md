# v0.9.0 tam site kontrolü

28 Ekim 2026 · Europe/Istanbul · Yerel oluşturulmuş yayın çıktısı.

## Bulunan ve düzeltilen sorunlar

- EN/TR sorun giderme rehberindeki eski “modelsiz V4 ekleme 503 döndürür”
  iddiası düzeltildi; combined tüketici koşulu ve BM25 davranışı açıklandı.
- Colab sayfasının emekli başlığı ve gizli menü kaydı güncellendi.
- İngilizce belge başlıklarındaki yinelenen MESA adı kaldırıldı.
- Belgeler girişindeki Python aralığı 3.11–3.13 olarak düzeltildi; başlangıç
  kartı yeni yerel belge ekleme/arama akışını anlatıyor.
- Denetim sayfasındaki kaldırılma tarihi v0.8.1 olarak düzeltildi ve sayfada
  bulunmayan test eki yerine gerçek test rehberine bağlantı verildi.
- Başlangıç anlatımında modellerin ve Kùzu çizgesinin isteğe bağlı olduğu açıklandı.
- Türkçe araştırma başlığının 320 px ekranda oluşturduğu 4 px taşma giderildi;
  dar ekran yazı boyutu ve uzun sözcüklerin satıra bölünmesi iyileştirildi.
- SQLite dersindeki metin içi bağlantılar renkten bağımsız ayırt edilebilmeleri
  için altı çizili gösteriliyor. Düzeltme ortak ders bağlantı stilinde yapıldı.

Ana sayfa, Core, mimari, nasıl çalışır, dokümantasyon, hızlı başlangıç, API,
dersler, Data, ekosistem, Law ve sertifikasyon sayfalarının EN/TR mobil ve

Axe'ın gradyan arka planlar nedeniyle otomatik karar veremediği kontrast
örnekleri tam WCAG sertifikası olarak yorumlanmadı. Gerçek üretim Auth servisi
ve canlı form teslimatı çalıştırılmadı; admin/form kontrolleri, dış sisteme veri
yazmayan yerel fixture yanıtlarını kullanır. Dış bağlantıların tamamına HTTP
isteği gönderilmedi; iç dosya/anchor doğrulaması ve değiştirilen Core kaynak
bağlantılarının Git nesnesi doğrulaması ayrı yapıldı.

## Yeniden çalıştırma

Yerel HTTP önizlemesi açıkken:

```bash
node scripts/check_browser_layout.mjs --all-pages --base-url http://127.0.0.1:8009/ --screenshots /tmp/mesa-all-pages
node scripts/check_browser_layout.mjs --axe-only --axe-source node_modules/axe-core/axe.min.js --base-url http://127.0.0.1:8009/ --screenshots /tmp/mesa-axe
npm test
python3 scripts/check_site.py _site
python3 scripts/check_public_artifact.py _site
```

Kanıtlar `photos/review/v0.9.0/` altında: `all-pages-final/observations.json`,
`accessibility-final/observations.json`, `admin-fixture/observations.json`,
`typography-final.json` ve ekran görüntüleri. Değişiklikler yerelde; bu kontrol
commit, push veya dağıtım yapmadı.
