## 1. Technical SEO Implementation

Every page generated by the build pipeline adheres strictly to search engine optimization standards:

1. **Heading Hierarchy:**
   - Exactly one `<h1>` per page (`main_count = 1`, `h1_count = 1` verified by `check_site.py`).
   - Strict hierarchical order: `h1` → `h2` → `h3` with no skipping of heading levels.
2. **Metadata & Open Graph:**
   - Descriptive `<title>` tags (format: `{Title} — MESA` or `{Title} · MESA`).
   - Unique `<meta name="description">` per route, accurately summarizing page contents without keyword stuffing.
   - Comprehensive Open Graph metadata: `og:title`, `og:description`, `og:url`, `og:image`, `og:locale` (`en_US` or `tr_TR`), `og:locale:alternate`.
   - Twitter card metadata: `summary_large_image`, `twitter:title`, `twitter:description`, `twitter:image`.
3. **Canonical & Multi-language Linking:**
   - Canonical URLs point to the authoritative domain `https://mesamemory.dev/`.
   - Bi-directional hreflang alternates (`en`, `tr`, `x-default`) declared on every page.
4. **Structured Data (JSON-LD):**
   - Core pages declare `@type: WebSite` and `SoftwareSourceCode` schema nodes linking directly to the open-source GitHub repository.
   - Hub sections declare `@type: BreadcrumbList` navigation hierarchy.
   - Educational articles declare `@type: Article` with author, publisher, publication date, modification date, and headline.
5. **Crawl Directives:**
   - `sitemap.xml`: Contains all 74 localized URLs with hreflang alternate declarations.
   - `robots.txt`: Grants universal crawl access (`Allow: /`) and references the canonical sitemap.

## 2. Accessibility & Usability (WCAG 2.1 AA/AAA)

1. **Color Contrast:**
   - Ink on dark surfaces (`#e8eaf0` on `#11131b`): **16.2:1** (Exceeds WCAG AAA).
   - Muted text on dark surfaces (`#a5a9b5` on `#11131b`): **7.89:1** (Exceeds WCAG AAA).
   - Metadata on dark surfaces (`#858b98` on `#11131b`): **5.42:1** (Exceeds WCAG AA).
   - Control boundaries on surfaces (`#666c7c` on `#11131b`): **3.53:1** (Exceeds WCAG non-text 3:1).
2. **Focus States & Keyboard Navigation:**
   - Accessible skip link (`<a class="skip-link" href="#main-content">Skip to content</a>`).
   - High-visibility focus ring on all interactive elements: `outline: 2px solid var(--focus); outline-offset: 4px;` with contrast ratio **12.01:1**.
   - Interactive disclosure elements (`<details>` / `<summary>`) are natively keyboard-accessible with standard Enter/Space activation.
3. **Motion Accessibility:**
   - Respects user preference via `@media (prefers-reduced-motion: reduce)`.
   - Animated SVG graph segments and transitions disable motion when requested, ensuring readability and comfort for vestibular-sensitive users.
4. **Screen Reader Readiness:**
   - Decorative visual assets and SVGs include `aria-hidden="true"` or `role="presentation"`.
   - Semantic landmarks: `<header>`, `<nav>`, `<main>`, `<aside>`, `<footer>`, `<section>`, `<article>`.
