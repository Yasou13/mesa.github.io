# Information architecture

Home now follows hero → concrete problem → source/ingestion/persistence/retrieval flow → deterministic fixture and illustrative RRF arithmetic → three editorial capabilities → Data/Core/Law plus QA/E2E quality rail → pinned developer start. Primary action opens documentation; secondary opens the official repository. Existing section anchors, including `why-mesa`, `mesa-in-action`, `how-it-works`, `ecosystem` and `continue-exploring`, remain.

The main navigation exposes Architecture in the former Use Cases slot. `/use-cases/` remains public and linked in the footer. `/architecture/` separates logical ingestion, physical stores, retrieval execution and evidence identity. `/retrieval/` explains lane purpose, exact fusion, citation/legal ranking, operational failures and context limits.

The documentation gateway starts with a five-step reading journey and retains the categorized contract index. Core sidebar groups: Start here; Core concepts; Retrieval; Integration & reference; Operate & recover; Release & evidence. Mobile sidebar uses a native disclosure; desktop expands it as an enhancement. The source appendix is a separate native disclosure; fragment links reveal original sections. Previous/next links and all original routes are retained.

Eleven new native Core routes cover documentation-map, security, operations, ecosystem, testing, release-policy, MCP, embedding-providers, evidence, graph and examples. Four focused editorial topics point to existing maintained files rather than pretending upstream has separate files. All are paired with `/tr/` routes and indexed for search, sitemap, canonical and hreflang.
