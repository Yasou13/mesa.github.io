# SEO, accessibility and performance

Static gate: 176 localized routes, 179 HTML files, **14,643 internal references** and **1,939 external references** passed. Checks cover headings/IDs, canonical and locale metadata, hreflang, titles/descriptions, social metadata, structured WebSite/SoftwareSourceCode/TechArticle/Breadcrumb content, sitemap membership and safe destinations. Link checks establish local paths and fragment existence; immutable source-file existence is separately verified. No keyword stuffing, hidden SEO content or invented benchmarks were added.

Browser evidence: 260 observations in the primary matrix (all 176 routes at representative widths, home at 12 widths in both languages, existing representative pages at six widths); 84 additional observations for seven technical views at six widths in EN/TR; eight final home/docs snapshots. Zero final overflow or unexpected broken-image failures. Home fixture starts at 1,725px EN / 1,744px TR at 390px width. Primary matrix maximum observed load CLS: 0.022536; extended technical matrix maximum 0.000061; final eight home/docs snapshots CLS=0.

Axe-core **4.14.0**, official registry integrity verified, was injected only into local test pages. Tags: wcag2a, wcag2aa, wcag21aa, wcag22aa and best-practice. **176/176 public routes, zero automatic violations**. Final incomplete findings: {'color-contrast': 162}. Remaining incomplete items concern gradients, pseudo-elements and non-text decorative characters; they are retained verbatim in `evidence/axe-all-routes.json`. This is automated accessibility evidence, not complete WCAG conformance certification. Selected EN/TR screenshots were visually reviewed; full assistive-technology/manual contrast certification was not performed.

Keyboard/browser checks include native Space interaction with lane inputs, visible focus, search focus trap/Escape/restoration, menu, source/fixture disclosure, original-source fragment opening, admin isolation, no-JS reading/navigation and calculator fallback, reduced motion and failed decorative imagery.

Same local cold-cache harness, no HTTP compression/throttling: mobile home resource transfer was 988,266 bytes before, 342,265 bytes in the final snapshot (**65.4% lower**). This excludes the main HTML document and is local resource evidence, not a network benchmark. Main savings are the 535KB logo derivative and WOFF2 fonts. Final snapshots report 330,468–342,265 resource bytes. Runtime JS remains small and dependency-free. No Lighthouse score, field Core Web Vitals, p95 latency or provider quality result is claimed.

Tool references: [axe API](https://github.com/dequelabs/axe-core/blob/develop/doc/API.md), [FontTools subset](https://github.com/fonttools/fonttools). Context7 was used for FontTools documentation; the later axe Context7 lookup failed, so official upstream API documentation was consulted. Testing assets are not shipped.
